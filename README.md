> Антивирус может предупредить о WinDivert.

>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert рискованными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии обнаружения обязательно будет `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить папку с zapret в исключения или отключить обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, для этого служит параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить их; если не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика, отличный от варианта «Поставщик по умолчанию».
    * В Firefox откройте «DNS через HTTPS», выберите режим «Персональный», затем «Выбрать провайдера/поставщика» и вручную укажите URL. Например, `https://dns.google/dns-query`: поставщик Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить в параметрах самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр «Транзит запросов». Если его отключить, настройка и использование Secure DNS на компьютере могут работать некорректно.

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/AuraAirDestroy/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и отметьте «Разблокировать». При распаковке через 7-Zip или PeaZip этот шаг не нужен.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу или специальные символы.

5. Запустите нужный скрипт.
    * Чтобы найти подходящую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автозапуск: **`service.bat`** → `Install Service` → выберите подходящую стратегию.

## ℹ️ Краткое описание файлов

- [**`general.bat ...`**](./general.bat) — запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому испытайте разные варианты, в том числе **ALT, FAKE и другие**, пока не найдёте подходящий.

- [**`service.bat`**](./service.bat) — скрипт для настройки автозапуска и управления функциями:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** — показывает состояние обхода и служб: стратегии автозапуска и WinDivert.
  - **`Game Filter`** — включает или отключает режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После смены режима стратегию нужно перезапустить.  
  В скобках отображается, включён режим или выключен.
  - **`IPSet Filter`** — задаёт режим обработки сервисов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который доступен без zapret, но перестал работать с ним.  
  Текущее состояние указано в скобках:
    - `none` — ни один IP-адрес не проверяется
    - `loaded` — IP-адрес сверяется со списком
    - `any` — фильтр применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включает или выключает автоматическую проверку обновлений.
  - **`Replace active fakes`** — меняет активный фейк на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загружает актуальный список `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** — вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** — ищет типичные причины проблем с zapret.  
  В конце проверки можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь, если приложение внезапно перестало работать.
  - **`Run Tests`** — открывает проверку работоспособности стратегий:
    - `Standard tests` — проверяет сайты, перечисленные в `utils/targets.txt`.
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным BAT-файлом, не через service, должен появиться `winws.exe` — процесс обхода, который виден на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues/522).

### Не подошла ни одна стратегия
- Запустите командную строку с правами администратора.
- Введите команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущая версия hosts устарела, программа предложит обновить её вручную:  
  - Скопируйте содержимое открытого Блокнота целиком.
  - Найдите файл `hosts` в показанной папке и откройте его текстовым редактором от имени администратора.
  - Вставьте скопированный текст в конец `hosts` (или замените им ранее добавленный текст такого же типа).
  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что изменения действительно записаны.

#### Результат не гарантирован. Если способ не сработал, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/AuraAirDestroy/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия способна работать какое-то время, а затем перестать обходить ограничения после обнаружения.
> В репозитории есть несколько вариантов обхода. Если ни один не подходит, создайте свою стратегию на основе существующей, изменив её параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` → `Run Diagnostics` и устраните обнаруженные ошибки.

- Убедитесь, что адрес нужного ресурса есть в списках доменов или IP-адресов.

- Проверьте другие варианты стратегий: **`ALT`**, **`FAKE`** и прочие.

- При необходимости выполните полную переустановку (инструкция ниже).

- Дополнительные сведения: [#765](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить zapret?
- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; устраните найденные проблемы и в конце введите Y.
- Удалите папку zapret.
- Загрузите последнюю версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/AuraAirDestroy/zapret-discord-youtube/releases).
- Нажмите правой кнопкой мыши на архив, откройте свойства и, если внизу справа есть параметр «Разблокировать», включите его. Нажмите «Применить», затем «ОК».
- Распакуйте архив в новую папку в корне диска; путь не должен содержать специальные символы или пробелы.
- По очереди запускайте скрипты `general` и проверяйте доступ к ресурсам. Если интернет-сайты не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` → `Install Service` → выберите стратегию.

### Игра или приложение не работает с включённым zapret

- В `service.bat` проверьте, что для `Game Filter` указано **`disabled`**, а для `IPSet Filter` — **`none`**. Иначе обход может затронуть ресурсы, для которых вы этого не ожидали.

### Античит сообщает о WinDivert

- Следуйте [инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в службах

1. В командной строке Windows узнайте имя службы. Откройте окно «Выполнить» сочетанием Win+R и введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив найденное имя вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с такими расширениями бороться.
- Если используемая стратегия раньше работала, проверьте остальные варианты.
- См. обсуждение [#251](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions/251).

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Сначала найдите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если и сайт не открывается, проверьте остальные стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/AuraAirDestroy/tg-ws-proxy).
- Другой вариант — бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игры отличаются друг от друга, поэтому проверить и исправить каждую из них возможности нет.

Обычно стоит сделать следующее:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если это не помогло, включите также параметр `ipset any`.

Учтите: при включённом `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Лучше выяснить IP-адреса, которые использует игра, и внести их в `ipset-all.txt`.

Если игра по-прежнему не работает, откройте обсуждение в разделе [Discussions](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions), а не в Issues, и дождитесь ответа других игроков.

### Здесь нет решения моей проблемы

- Опишите проблему [в Issues](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Добавьте адреса в соответствующий файл:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, это пригодится, если IP сети указан в `ipset-all.txt`, но конкретный домен из неё фильтровать не следует.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
